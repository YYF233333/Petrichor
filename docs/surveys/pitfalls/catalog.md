# Petrichor pitfall catalog

Engine and GDScript pitfalls, and C# (.NET) bridge pitfalls, that bite Godot 4 script authors. Engine facts were checked by reading godotengine/godot at commit 469659e0617345149cd1eaec2e643d61d130aa6a (master, 4.8-beta); `path:line` refers to that commit. Issue states and reaction counts were read from GitHub on 2026-10-23. Nothing was confirmed by running the engine; claims that would need a run are marked "unverified (needs repro)".

Fix classes (an inference for a new, non-.NET, statically typed script language and its toolchain): **L** language semantics; **T** static checking or toolchain; **W** runtime wrapper over public ClassDB/GDExtension APIs; **M** needs C++ APIs not exposed to GDExtension (module only); **E** needs an engine core change; **N/A** specific to .NET (the analog the new language would face is given in parentheses). A class such as "L+W (order itself: E)" means L and W remove the pitfall for code written in the new language, while the named engine behaviour stays.

Counts by primary class (the first class listed); "Any E residual" counts entries whose class string names an E part:

| Group | L | T | W | M | E | N/A | Total | Any E residual |
|---|---|---|---|---|---|---|---|---|
| engine/GDScript | 36 | 6 | 7 | 0 | 0 | 0 | 49 | 19 |
| C# | 13 | 3 | 4 | 0 | 1 | 10 | 31 | 2 |
| All | 49 | 9 | 11 | 0 | 1 | 10 | 80 | 21 |

No entry needs M. N/A analogs: L 7, T 2, W 1.

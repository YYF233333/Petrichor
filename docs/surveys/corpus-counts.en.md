# Survey: one-off counts in the corpus

**2026-10-25** · Related: [language specification](../language-spec.en.md) · 中文：[corpus-counts.zh.md](corpus-counts.zh.md)

Some rules in the specification need only a single count as evidence. This document collects such counts over the corpus of the [cross-branch duplication survey](cross-branch-duplication.en.md): 20 repositories at fixed commits, first-party `.gd` files only, 203,720 code lines (blank and comment lines excluded). The counts come from lexical analysis without type resolution; `!` is counted only when not directly followed by `=`. In GDScript `...` appears only in function signatures (`modules/gdscript/gdscript_parser.cpp:1714, 4336` at Godot `469659e`), so every `...` directly followed by a name is a rest parameter. A coroutine is a method whose body contains await; references to it are looked for only in the same file, and signal connections in scenes are not counted. The captures of a lambda are the parameters and locals that its method declares before it, other than the lambda's own. `get_parent()` and `owner` are counted only on self, that is, when not preceded by `.`; a test for null is a comparison with null, use as a condition or as the argument of `is_instance_valid`, and also such a test, within the next 25 lines, of a variable assigned from them. `free()` and `set_script(...)` are on self when not preceded by `.`, or written after `self.` or `super.`. Strings are found by scanning the text outside comments, with backslash escapes and the `r` prefix as GDScript reads them. The uses of a constant initialized with a preload are looked for only in the file that declares it: as a type means after `:`, `->` or `as`, or in `Array[...]`; node paths `$Name` and `%Name` are not counted. An enum's uses count where its name is written alone or after a class_name of the same repository, so uses through preloaded constants are missed; its values are known when each is an int literal or follows one. An inner class is `class` first on a line, after any annotations, and its body the lines indented deeper; a bare use inside it of a name the outer class declares counts unless the inner class, its locals or its engine base declare the name too; `Name.Inner` from another file is resolved through class_names, preloaded constants and autoloads (`project.godot`). A `static var` without an initializer is classed by the spelling of its type: a built-in type is a type name of Variant.
